04 / METHODOLOGY

How to read this data.

  • Source: Netflix Movies and TV Shows (Kaggle); additions through September 25, 2021.
  • The production country field is comma-separated; 'Pakistan' is matched as an exact token.
  • Each multi-country production is counted for each credited country, not exclusively.
  • Categories and genres can overlap; label totals need not equal unique title counts.
  • Missing countries are unknown; content ratings are classifications rather than reviews.
  • No Netflix Pakistan viewership, subscriber, availability or revenue data is present.
  • Source transformations, chart definitions, and reproduction scripts are included in the GitHub repository.
